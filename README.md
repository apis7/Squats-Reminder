# Squats Reminder

A Python-based application that reminds you to do squats at regular intervals to maintain physical fitness during long periods of sitting.

## Features

- Customizable reminder intervals
- Audio notifications
- System tray integration
- Multiple audio options for notifications

## Technology Stack

- Python 3.x
- PyQt5 for GUI
- PyInstaller for executable packaging

## Note

This project was 100% Agenic Coded using Qwen Code.

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `python src/main.py`

## Building

To build the executable:
```
pyinstaller SquatReminder.spec
```
